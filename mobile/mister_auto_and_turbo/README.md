# Mister Auto & Turbo - Customer App (Flutter)

Customer-facing mobile application for the Mister Auto & Turbo Vehicle Service Management System.

## Stack
- Flutter / Dart
- Provider (state management)
- Supabase (backend)

## Getting Started

```bash
cd mobile/mister_auto_and_turbo
flutter pub get
flutter run
```

Configure Supabase credentials in `lib/config/supabase_config.dart`.
